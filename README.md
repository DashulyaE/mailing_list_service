# Сервис управления рассылками, администрирования и получения статистики 
## Описание проекта:
Данное приложение позволяет пользователям управлять рассылками сообщений для клиентов.

## Установка:

1. Клонируйте проект в свой репозиторий по ссылке:
```
git clone github.com/DashulyaE/mailing_list_service
```

## Реализованы задачи проекта:
Создана общая директория для проекта и настроено виртуальное окружение.
Все зависимости для виртуального окружения хранятся в файле pyproject.toml

В директории mailingserv реализованы задачи:
1. Управление клиентами
2. Управление сообщениями
3. Управление рассылками
4. Отправка сообщений по требованию
5. Сохраняются попытки рассылок
6. Формируется статистика количестве успешных/
неуспешных попыток рассылок пользователя и количестве отправленных сообщений

В директории *users* реализованы задачи регистрации пользователей в сервисе.

-Для запуска сервера используйте команду:

```
python manage.py runserver
```
- Перейдите по ссылке, появившейся в консоли после
запуска серевра, например: http://127.0.0.1:8000/
- В проекте в директории *mailingserv/managements/commands/create_managers_group.py*
расположена комманда для создания группы "Менеджеры" и там же определены права
для пользователей, которые будут относится к этой групее доступа
- В проекте в директории *users/managements/commands/csu.py*
расположена команда для создания суперпользователя. Эту команду необходимо запустить,
если вы вносили какие-либо изменения в модели и сделали миграции.
